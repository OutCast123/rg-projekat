
# Projekat SV

Projekat studenta Strahinje Vasiljevic broj indeksa mi121/2024 za predmet Računarska Grafika 


## Implementacije


*Petlja Renderovanja

*Menjanje veličine ekrana strelicama- 

                    Ctrl+levo ->Povećava se širina ekrana

                    Ctrl+desno ->Smanjuje se širina ekrana

                    Ctrl+gore ->Smanjuje se visina ekrana

                    Ctrl+dole ->Povećava se visina ekrana


*Klikom na taster Space boja pozadine se menja na nasumičnu

*Klikom miša na ekran boja pozadine se menja u random boju

*Pritiskom na Shift pa na ekran boja ekrana se menja u formatu (x, y,0) gde je (0,0,0) donji levi ugao ekrana, a (1.0 ,1.0 ,0) gornji desni ugao.

*Esc gasi aplikaciju
